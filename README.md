# Reinforcement Learning

Tabular reinforcement learning experiments focused on multi-agent coordination.

## Project

### Multi-Agent Q-Learning: Grid-World Coordination
`Tabular Q-learning agent.ipynb`

Four agents learn to coordinate in a 5×5 grid world using tabular Q-learning. The problem: agents must navigate from pickup point A to drop-off point B while avoiding collisions with each other.

**Key concepts:**
- Tabular Q-learning (no function approximation)
- Multi-agent coordination under collision constraints
- Reward shaping and convergence analysis
